## Overview

This repository contains the code used to reconstruct synthetic metaorders from anonymous transaction and quote data and to evaluate their consistency with the Lillo–Mike–Farmer (LMF) order-splitting theory. The analysis uses data for 239 Johannesburg Stock Exchange securities and evaluates candidate reconstruction configurations against established metaorder stylised facts and the LMF exponent relation. The repository includes the data-processing, metaorder-reconstruction, model-evaluation, and figure-generation code used in the accompanying master's thesis pre-print. 

## Abstract

Market-order flow in financial markets exhibits long-range autocorrelations, whereby the signs of successive market orders remain correlated over relatively long time horizons. A popular hypothesis for this empirical phenomenon is the order-splitting mechanism proposed by Lillo, Mike and Farmer (LMF), in which larger (parent) orders are divided into a sequence of smaller (child) orders. Quantitative tests of this theory have historically relied on proprietary datasets that contain broker and trader identifiers, limiting reproducibility and cross-market validation. This dissertation investigates whether it can be recovered from anonymous public data using synthetic metaorder generation. The analysis uses transaction and quote data for the 239 stocks for which data was available from the 250 largest stocks by market capitalisation on the Johannesburg Stock Exchange (JSE), as determined on 13 March 2026. The data covers the period from 1 January 2023 to 31 December 2025. Synthetic metaorders are generated by grouping the observed transactions according to a range of generation parameters. A grid search is then used to evaluate these configurations against established empirical properties of metaorders as well the principal quantitative relationship between the persistence of order-flow and the metaorder run length distribution which is implied by the LMF theory. The results reveal an interesting asymmetry. Configurations selected to reproduce the aggregate metaorder stylised facts successfully recover the targeted metaorder impact properties but produce poor correspondence with the LMF relation. In contrast, configurations selected to minimise the discrepancy with the LMF relation recover the theoretical relation while retaining several broad metaorder impact features, although some stock-level execution and decay fits are weaker. These asymmetric results show that recovering aggregate metaorder impact stylised facts alone is insufficient to identify LMF-consistent order splitting, while the LMF-targeted result establishes compatibility within the generation class rather than an independent test. The findings support consistency with, rather than direct validation of, the LMF theory using anonymous market data.

### Folder Descriptions

#### `Calibration_results/`

Contains a CSV file containing the grid search results used to select optimal configurations based on the three calibration objectives.

#### `Data_processing_notebooks/`

Contains Jupyter notebooks used to:

- Retrieve limit order book data from the BMLL platform.
- Process and clean the raw data.
- Generate synthetic metaorders.
- Perform the grid search over generation parameters.

#### `Plotting_notebooks/`

Contains notebooks used to analyse calibration results and reproduce the figures presented in the thesis, including:

- Market impact curves
- Independence plots
- Concave profile plots
- Impact decay plots
- Alpha-Gamma relationship plots

#### `Modules/`

Contains reusable Python modules implementing the core methodology developed in the thesis, including:

- Synthetic metaorder generation
- LMF model calculations
- Alpha and Gamma estimation
- Utility functions used across notebooks

#### `Stock_information/`

Contains a CSV file that contains information on the stocks included in the analysis, such as the tickers, company names, market capitalisation and other metadata required for filtering and interpretation of results.

### Workflow

1. Retrieve and pre-process the raw order data from BMLL using the `data_retriever_BMLL.pynb` file.
2. Perform a grid search and save the results to a CSV file using the `grid_search_BMLL.pynb` file.
3. Retrieve, process, find optimal configurations for each objective, and then generate synthetic metaorders using the optimal configuration settings using the `calibration_results_BMLL.pynb` file.
4. Plot the relevant plots for the optimal configurations when minimising $e_{\mathrm{M}}$, $e_{\mathrm{LMF}}$ and $e_{\mathrm{combo}}$. This can be done using the `impact_curves_plots_BMLL.pynb`, `time_independence_plots_BMLL.pynb`, `concave_profile_plot_BMLL.pynb`, `decay_plots_BMLL.pynb`, `alpha_gamma_plots_BMLL.pynb`.
